# LIC document pipeline - shared dependencies (CPU and GPU alike).
#
# This file deliberately does NOT pin an onnxruntime build. All three
# distributions (onnxruntime, onnxruntime-gpu, onnxruntime-directml) install the
# same importable `onnxruntime` package, so installing two of them leaves a
# half-overwritten mixture whose available providers depend on which was
# unpacked last. Pick exactly one:
#
#     pip install -r requirements.txt
#     pip install -r requirements-gpu.txt     # NVIDIA GPU present
#     pip install -r requirements-cpu.txt     # no NVIDIA GPU
#
# Or let it be decided for you, which also repairs an existing broken mixture:
#
#     python setup_runtime.py
#
# The pipeline detects at startup which provider it actually got, so the same
# code runs on either machine with no flags (see ocr_engine.cuda_available).
